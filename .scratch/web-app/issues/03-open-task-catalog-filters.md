# 03: Общий каталог задач с живой фильтрацией и спидометрами

**What to build:** Страница открытого общего каталога подтвержденных бизнес-задач (`/catalog`). Карточки задач отсортированы по убыванию рейтинга готовности. Живой поиск по названию и контексту потребности, фильтрация по отраслям и уровням готовности (Приоритетная, Готовая, Рабочая, Черновик). В каждой карточке отображаются метаданные, отрасль, направление, бейдж готовности и компактный круговой SVG-спидометр (0–100 баллов).

**Blocked by:** 01: Серверное ядро FastAPI и чистый белый каркас сайта

**Status:** ready-for-agent

- [ ] Страница `/catalog` отображает все подтвержденные задачи из `Storage`.
- [ ] Задачи по умолчанию отсортированы по убыванию рейтинга готовности.
- [ ] Работает клиентская или серверная фильтрация по отрасли и уровню готовности.
- [ ] Работает мгновенный поиск по строке запроса в названии и тексте потребности.
- [ ] В каждой карточке отрендерен компактный круговой SVG-спидометр с корректным цветовым уровнем.
- [ ] Тесты подтверждают корректность отдачи каталога и фильтрации через `TestClient`.
- [ ] В разметке и коде строго 0 эмодзи.
