# 07: Защита от сгорания XP при подтверждении этапа без команды

**What to build:**
Устранить дефект сгорания XP (Spec finding C.1 / User Stories 19, 21): запретить подтверждение этапа задачи, если у задачи еще не выбрана команда-исполнитель (`accepted_proposal is None`), либо гарантировать привязку начисленных очков. В `templates/business.html` визуально блокировать кнопку «Подтвердить этап (+XP)» с поясняющей подсказкой «Сначала выберите команду-исполнителя». В `server.py` эндпоинт `/api/milestones/{task_id}/{milestone_id}/complete` должен проверять наличие принятой команды и возвращать HTTP 400 с понятным сообщением при попытке закрыть этап до выбора исполнителя.

**Blocked by:** None (can start immediately)

**Status:** closed
