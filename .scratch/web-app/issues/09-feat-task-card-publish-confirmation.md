# 09: Предпросмотр и явное подтверждение публикации карточки задачи

**What to build:**
Реализовать явный шаг предпросмотра сформированной карточки задачи перед ее публикацией в общий каталог (Spec finding A.2 / User Story 6). После завершения AI-интервью и генерации карточки в Конструкторе (`templates/index.html`) пользователь должен видеть детальный предпросмотр карточки с рейтингом готовности (0–100) и две кнопки: «Опубликовать в каталог» и «Сохранить как черновик». Эндпоинт создания/публикации должен явно фиксировать намерение пользователя (`published: True` только по подтверждению).

**Blocked by:** None (can start immediately)

**Status:** open

- [ ] Написать TDD-тест в `tests/test_web_app.py`, проверяющий сохранение черновика без флага публикации и отдельный эндпоинт/параметр подтверждения публикации.
- [ ] В `server.py` обновить логику сохранения карточки: поддерживать флаг публикации по запросу клиента (`published: bool = True/False`).
- [ ] В `templates/index.html` добавить экран предпросмотра карточки перед финальной публикацией с кнопками «Опубликовать в общий каталог» и «Сохранить черновик».
- [ ] Проверить, что неопубликованные черновики не попадают в общий каталог `/catalog`, а опубликованные появляются мгновенно.
- [ ] Все тесты в `tests/` проходят успешно (`./venv/bin/pytest tests/`).
- [ ] В коде и верстке строго 0 эмодзи.
