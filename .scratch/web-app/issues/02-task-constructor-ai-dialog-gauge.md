# 02: Конструктор задачи с AI-диалогом и спидометром рейтинга

**What to build:** Интерактивная страница Конструктора бизнес-задачи (`/` и `/constructor`). Ввод черновика потребности с выбором отрасли и направления, кнопка быстрой вставки эталонного черновика для показа жюри. Пошаговый диалог с AI (генерация вопросов через `AIGenerator`, отображение истории ответов, кнопка «Быстрый ответ для жюри»). Финальная сборка подтвержденной карточки задачи с динамическим круговым SVG-спидометром рейтинга готовности (0–100 баллов, 4 цвета), списком рекомендаций по улучшению и списком контрольных этапов (milestones).

**Blocked by:** 01: Серверное ядро FastAPI и чистый белый каркас сайта
