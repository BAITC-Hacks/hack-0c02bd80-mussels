# 06: Экспресс-демонстрация для жюри, скрипт run_web.sh и аудит

**What to build:** Страница экспресс-демонстрации (`/jury-demo`), позволяющая жюри или спикеру в 1 клик пройти сквозной сценарий платформы: загрузка эталонного черновика -> пошаговые ответы -> расчет рейтинга на спидометре -> подача отклика -> принятие контрольного этапа -> начисление XP. Скрипт быстрого запуска `./run_web.sh`. Автоматический аудит на строгое отсутствие эмодзи и проверка всех тестов через `pytest`.

**Blocked by:** 02: Конструктор задачи с AI-диалогом и спидометром рейтинга, 03: Общий каталог задач с живой фильтрацией и спидометрами, 04: Кабинет бизнеса с интерактивной шкалой контрольных этапов (+XP), 05: Кабинет студенческой команды с карточками XP и рекомендациями
