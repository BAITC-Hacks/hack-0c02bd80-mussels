# 04: Кабинет бизнеса с интерактивной шкалой контрольных этапов (+XP)

**What to build:** Страница Кабинета бизнеса (`/business`). Просмотр задач компании, перечня откликов студенческих команд с кнопками ручного выбора («Выбрать команду» / «Отклонить» — строго без автоназначения). Интерактивная шкала контрольных этапов (milestones) с процентом выполнения (например, 2 из 3 этапов завершено, 66%) и суммой начисленных XP. Кнопка «Подтвердить этап (+XP)» у каждого активного этапа, которая асинхронно обновляет статус в `Storage`, начисляет баллы команде и плавно обновляет шкалу без перезагрузки страницы.

**Blocked by:** 01: Серверное ядро FastAPI и чистый белый каркас сайта

**Status:** ready-for-agent

- [ ] Страница `/business` отображает задачи бизнеса и список откликов студенческих команд.
- [ ] Кнопки «Выбрать команду» и «Отклонить» работают в ручном режиме согласно ADR-0003.
- [ ] Отображается шкала прогресса контрольных этапов с корректным расчетом процента и баллов XP.
- [ ] Эндпоинт `POST /api/milestones/{task_id}/{milestone_id}/complete` фиксирует дату и статус `completed`, а также добавляет очки команде.

- [ ] Тесты в `tests/test_web_app.py` проверяют валидность начисления очков и смены статуса этапа.
