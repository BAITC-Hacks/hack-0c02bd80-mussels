# 01: Серверное ядро FastAPI и чистый белый каркас сайта

**What to build:** Полноценный запуск локального веб-сервера на базе FastAPI на порту 8000 с поддержкой Jinja2 и Tailwind CSS. Базовый шаблон `templates/base.html` с фиксированной белой шапкой (Sticky Navbar): логотип AI Sana, меню разделов («Конструктор», «Каталог», «Кабинет студента», «Кабинет бизнеса», «Демо жюри»), индикатор текущего режима AI (OpenAI API / Локальный движок), кнопка сброса базы к исходному сид-набору и подвал сайта. Полный запрет на эмодзи.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Сервер `server.py` запускается и отвечает на `http://localhost:8000` с кодом HTTP 200.
- [ ] Шаблон `templates/base.html` содержит чистый белый дизайн (Clean Tech White) с Tailwind CSS и Alpine.js.
- [ ] В шапке сайта отображается логотип AI Sana, навигация по 5 разделам, статус AI-движка и кнопка сброса базы.
- [ ] Эндпоинт `POST /api/reset-data` успешно сбрасывает данные в `data/*.json` к начальным 5 черновикам, карточкам и командам.
- [ ] Написан базовый тест в `tests/test_web_app.py`, проверяющий доступность главной страницы через `TestClient`.
- [ ] В разметке и коде строго 0 эмодзи.
