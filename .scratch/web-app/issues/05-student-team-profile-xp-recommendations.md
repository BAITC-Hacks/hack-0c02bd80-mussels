# 05: Кабинет студенческой команды с карточками XP и рекомендациями

**What to build:** Страница Кабинета студенческой команды (`/student`). Виджет сводной статистики XP (общий баланс, число завершенных этапов, потенциал очков в работе). Именные карточки начисления XP за подтвержденные контрольные этапы с указанием даты и задачи. Блок многомерных персональных AI-рекомендаций задач (расчет по формуле: 40% домен, 40% стек, 20% готовность) с выводом бейджа совпадения и обоснования от AI.

**Blocked by:** 01: Серверное ядро FastAPI и чистый белый каркас сайта

**Status:** ready-for-agent

- [ ] Страница `/student` отображает профиль выбранной студенческой команды.
- [ ] Виджет сводки корректно считает и отображает заработанные XP, число закрытых этапов и потенциал очков.
- [ ] Карточки начисления XP отображают название задачи, этапа, начисленные очки (+XP) и дату подтверждения.
- [ ] Блок рекомендаций задач рассчитывает проценты соответствия через `calculate_recommendation_score` и выводит карточки с объяснениями.
- [ ] Доступен открытый переход к любой задаче из каталога (рекомендации не блокируют выбор).
- [ ] Тесты подтверждают корректность рендеринга профиля команды и расчета сводки XP.
- [ ] В разметке и коде строго 0 эмодзи.
