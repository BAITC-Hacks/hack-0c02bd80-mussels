# 08: Отклик студенческой команды на задачу из каталога

**What to build:**
Реализовать полноценную подачу отклика студенческой команды на задачу из Каталога (Spec finding A.1 / User Story 17). В бэкенде `server.py` реализовать эндпоинт `POST /api/proposals`, принимающий `task_id`, `team_id` и `cover_letter`/`message`, валидирующий входные данные и сохраняющий отклик через `storage.add_proposal`. В `templates/catalog.html` заменить статичную ссылку `/student` на интерактивную форму или модальное окно подачи отклика с возможностью выбора студенческой команды, ввода комментария и мгновенной отправки без перезагрузки страницы с показом уведомления об успехе.

**Blocked by:** None (can start immediately)

**Status:** open

- [ ] Написать TDD-тест в `tests/test_web_app.py`, проверяющий эндпоинт `POST /api/proposals` на создание отклика в хранилище и предотвращение дублирования.
- [ ] В `server.py` реализовать маршрут `POST /api/proposals` с Pydantic-моделью запроса (`task_id`, `team_id`, `message`).
- [ ] В `templates/catalog.html` добавить модальное окно или дропдаун/кнопку отклика студента с выбором команды и отправкой через fetch.
- [ ] Проверить отображение созданного отклика в Кабинете бизнеса (`/business`) среди входящих заявок.
- [ ] Все тесты в `tests/` проходят успешно (`./venv/bin/pytest tests/`).
- [ ] В коде и верстке строго 0 эмодзи.
