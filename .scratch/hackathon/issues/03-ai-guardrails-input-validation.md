# 03: Защитные гарды AI и валидация ввода

**What to build:**
Усиление системных промптов `AIGenerator` защитой от галлюцинаций (strict groundedness), валидация пользовательского ввода (фильтрация слишком коротких или бессмысленных строк) и автоматическая обработка сетевых сбоев с переключением на локальный генератор.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Валидатор входного текста черновика (минимальная длина, запрет пустого ввода)
- [ ] Защита системного промпта от добавления фактов, не указанных пользователем
- [ ] Юнит-тесты на устойчивость к сбоям API и невалидному JSON
- [ ] Полное сохранение работоспособности при отключенном ключе
