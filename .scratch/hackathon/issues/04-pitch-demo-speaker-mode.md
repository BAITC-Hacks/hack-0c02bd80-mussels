# 04: Режим спикера для 5-минутной защиты (Pitch Demo Guide)

**What to build:**
Встроенная шпаргалка и навигатор для спикера на защите: таймер на 5 минут, тезисы для каждого из 8 шагов пользовательского сценария и индикация критериев оценки хакатона.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Вкладка или панель экспресс-демо с пошаговыми подсказками спикеру
- [ ] Отражение всех 8 шагов сценария регламента (Черновик -> Уточнение -> Карточка -> Рейтинг -> Каталог -> Отклик -> Решение -> Прогресс)
- [ ] Кнопка 1-клик загрузки эталонных данных для демонстрации без ручного ввода
- [ ] Полное отсутствие эмодзи в интерфейсе
