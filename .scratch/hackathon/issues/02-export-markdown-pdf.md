# 02: Модуль экспорта карточек и предложений в Markdown

**What to build:**
Возможность для бизнеса и студентов выгрузить утвержденную карточку задачи или поданный отклик в виде чистого Markdown-файла в 1 клик для прикрепления к отчету хакатона или отправки в репозиторий.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Генерация чистого Markdown для утвержденной карточки задачи (со всеми 7 блоками и рейтингом)
- [ ] Кнопка `st.download_button` в карточке задачи для скачивания файла `.md`
- [ ] Генерация Markdown для поданных откликов команд в кабинете бизнеса
- [ ] Юнит-тест на корректность форматирования экспорта
- [ ] Полное отсутствие эмодзи в сгенерированных файлах
