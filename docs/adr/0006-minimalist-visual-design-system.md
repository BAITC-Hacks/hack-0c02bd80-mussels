# 6. Минималистичная дизайн-система и визуальный рефакторинг

Мы решили перевести интерфейс веб-приложения на строгий технологичный минимализм (Linear / Vercel style) на базе нейтральной палитры Zinc/Slate, типографики Plus Jakarta Sans и фокуса на ключевом артефакте платформы — Рейтинге готовности задачи.

### Контекст и причины
1. Первоначальный интерфейс использовал типовой для прототипов SaaS-набор: яркий цвет Indigo, разноцветные плашки карточек (желтые, синие, зеленые), тяжелые тени `shadow-sm`/`shadow-md` и эффект вложенных рамок («карточка в карточке»), создававший визуальный шум.
2. Согласно принципам минимализма («Spend boldness in one place») и глоссарию платформы, центральным фокусным элементом интерфейса должен быть интерактивный Рейтинг готовности (0..100) и диалог пошагового уточнения задачи, а не декоративные рамки и цветные плашки.
3. Для достижения высокого уровня эстетики перед финальной демонстрацией жюри утверждены следующие архитектурно-визуальные решения:
   - **Палитра**: Чистый белый фон (`#FFFFFF`), нейтральные графитовые градации (`zinc-900` для заголовков, `zinc-600` для основного текста, `zinc-400` для метаданных), тонкие деликатные границы `border-zinc-200/80` вместо тяжелых теней.
   - **Кнопки действий**: Монохромный графит (`bg-zinc-900 text-white hover:bg-zinc-800 active:scale-[0.98]`) для основных действий, что придает интерфейсу премиальную строгость.
   - **Типографика**: Подключение современного гротеска `Plus Jakarta Sans` / `Inter` с оптическим кернингом (`tracking-tight` для заголовков, спокойный вес `font-semibold` вместо `font-extrabold`).
   - **Навигация**: Ультратонкая полупрозрачная панель с размытием (`bg-white/80 backdrop-blur-md border-b border-zinc-200/60`).
   - **Детоксикация компонентов**: Устранение двойных вложенных рамок, группировка метаданных и увеличение свободного пространства (whitespace).
