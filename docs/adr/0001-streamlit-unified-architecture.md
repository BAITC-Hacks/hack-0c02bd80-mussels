# 1. Единая архитектура на базе Streamlit (Устарело / Superseded by ADR-0005)

*Статус: Заменено архитектурным решением ADR-0005 и полностью удалено из кодовой базы.*

Первоначально мы выбрали Streamlit в качестве быстрого монолитного прототипа для 4-часового лимита. Впоследствии, из-за ограничений в кастомизации интерфейса и стилей, Streamlit был полностью заменен на автономное веб-приложение на FastAPI (ADR-0005) и выведен из зависимостей проекта.
