# 1. Единая архитектура на базе Streamlit

Мы выбрали Python и фреймворк Streamlit в качестве монолитного стека (UI + логика + интеграция AI) вместо разделения на FastAPI и React/Next.js. В условиях жесткого 4-часового лимита хакатона это устраняет риск сбоев сетевой синхронизации (CORS, схемы REST API, развертывание двух сервисов), обеспечивает единое управление реактивным состоянием приложения и позволяет жюри запустить весь проект одной командой `streamlit run app.py`.
