# 4. Прозрачная аддитивная формула рейтинга готовности

Рейтинг задачи (0–100) рассчитывается строго по открытой аддитивной шкале: Контекст и потребность (20), Данные и материалы (20), Ожидаемый результат (15), Критерии успеха (15), Ограничения (10), Аудитория (10), Контакт (10). Баллы начисляются только за подтвержденные и содержательно заполненные блоки. Это делает систему прозрачной для жюри и мотивирует бизнес улучшать описание задачи ради поднятия позиции в общем каталоге.
