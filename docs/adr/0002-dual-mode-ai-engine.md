# 2. Двухрежимный генератор AI с бесшовным офлайн-фолбэком

Для выполнения критерия содержательной AI-функции и соответствия регламенту (надежность при отсутствии внешнего API) мы реализовали двухрежимную обработку: основным провайдером выступает OpenAI (модель `gpt-4o-mini`), а в случае таймаутов, отсутствия ключа или сетевых ошибок управление бесшовно передается детерминированному эвристическому генератору. Это гарантирует 100% работоспособность демонстрации в любых условиях без искажения фактов, переданных пользователем.
