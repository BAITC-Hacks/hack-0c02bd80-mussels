# 5. Переход к автономному веб-приложению на FastAPI и Tailwind CSS

Мы решили создать полноценный автономный веб-сайт на базе FastAPI, Jinja2, Tailwind CSS и Alpine.js на порту 8000, сохранив Streamlit (`app.py`) как резервную демонстрационную панель.

### Контекст и причины
1. Streamlit навязывает внутренние Emotion/React стили, что приводило к конфликтам тем оформления, нестабильной цветопередаче (особенно при включенном Dark Mode в ОС пользователя) и невозможности тонкого управления веб-дизайном.
2. Вся прикладная логика (формула скоринга `scoring.py`, AI-генератор `ai_generator.py`, многомерные рекомендации `recommendation.py` и файловое хранилище `storage.py`) полностью независима от Streamlit и напрямую переиспользуется веб-приложением.
3. Стек FastAPI + Tailwind CSS (CDN) + Alpine.js не требует установки Node.js или сборки npm-бандлов, обеспечивает полный контроль над каждым элементом белого дизайна, исключает зависимость от сторонних тем браузера и запускается одной командой `uvicorn server:app --port 8000`.
